# Navy Studio – animated portfolio (HTML + CSS only)
Pages: index, work, project-1..6, services, about, process, contact. Styles: style.css

## Run on localhost
A) VS Code: install the "Live Server" extension, right-click index.html > Open with Live Server (http://127.0.0.1:5500)
B) Terminal: python -m http.server 8000  (Mac: python3) then open http://localhost:8000
