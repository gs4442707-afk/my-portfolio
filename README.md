# Navy Studio v2 (HTML + CSS only)
Run: VS Code > Live Server > Open with Live Server, or: python -m http.server 8000
## Backgrounds
Home rotates 5 animated scenes (30s loop): Aurora, Edit timeline, Equalizer, Pulse rings, Bokeh. Inner pages each use one scene.
To use YOUR videos: add videos/scene-1.mp4 ... scene-5.mp4, then in index.html remove the <!-- --> around each <video> line.
